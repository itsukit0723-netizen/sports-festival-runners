# SPORTS FESTIVAL ARCADE

**[ゲームをプレイ](https://itsukit0723-netizen.github.io/sports-festival-runners/)**

BASKETBALL RUNNER / ROLLING FOOTBALL。スマートフォン・PCで遊べる2つのゲームです。

## 最新更新（2026-10-16・テストプレイ版）

- LOWは短めのジャンプで着地コインを回収、HIGH/LONGは大ジャンプ。通常の大ジャンプでも通過可能。
- サッカーに広い通路と狭い橙スター2倍ルートの選択区間を追加。橙の点線で合流を案内。
- 連続する難所の後に回収しやすい区間を設け、速度は維持。障害物数の比較は両ゲームとも1%未満の差。
- 自動テスト35件成功。結果画面とテスト用無敵ボタンは維持。

- バスケにジャンプの高さ調整を追加。短タップで小、約0.18秒の長押しで大。感圧対応端末は押す強さも反映。PCのクリック・SPACEは従来どおり。
- ジャンプ入力・高さ・キャンセル等を含む自動テスト30件成功。スマホ実機の感圧は未確認。

- バスケは50秒以降、毎秒少しずつ加速・高密度化。以前の120秒での難易度固定も解消。
- 両ゲームの通常時の障害物を増加。サッカーは通常4列・Hard5列へ変更。
- サッカーに横切る大型ボール、回転ゲート、ポールスラローム、混在区間を追加。
- 経路の曲がり方・間隔・幅を変化させ、同じ区間の連続を回避。
- 自動テスト26件成功。右上のテスト用無敵は引き続き使用できます。

### 前回のテストプレイ版

- バスケの表示回転を自然な速さへ再調整（4.8〜7.2rad/s）。
- 序盤から障害物を増やし、30秒・50秒以降も速度と密度が上がる構成へ変更。
- BONUS／FEVER中にも障害物を配置し、無敵で壊して進める区間を追加。
- コインとアイテムの重なり、地上列とジャンプ通路の重なり、画面内での突然の生成・消失を修正。
- 両ゲーム右上に一時的な「無敵 OFF/ON」、経過秒数、速度を追加。無敵を使用したプレイはBESTへ保存しません。
- 自動テスト22件成功。ソース内の `src/testing/REMOVE-TEST-CONTROLS.md` にテスト機能の完全撤去手順を記載。

### 前回更新

- コイン／スターをジャンプ軌道・安全な通路に沿って配置し、障害物の最大移動範囲も考慮。
- バスケは通常速度を約6％上げ、横長障害物を従来の約90％に縮小。
- バスケの表示回転を遅くし、BOOST／FEVERでは横方向だけ加速。ジャンプの高さ・落下・着地時刻は通常と共通。
- サッカーは月明かり・暖色照明の夜のコートへ変更。壁を金属フレームとパッド付きバリケードへ再設計。
- 自動テスト18件成功。

## 文化祭アプリへの組み込み用データ

[最新ソースZIP](./sports-festival-runners-source.zip) にReact / TypeScriptのソース、依存関係のロックファイル、テスト、起動手順を収録しています。Node.js 24で `npm ci` → `npm test` → `npm run build` を実行できます。

このリポジトリのルートは本番配信用です。ソースZIPを展開したファイルでルートをそのまま上書きせず、ビルドした `dist/` の中身を配置してください。

最高記録は端末とブラウザーごとの保存です。共通ランキングやアカウント連携は別途接続が必要です。
